计算图定义

计算图（computational graph）是一种被用于pytorch与tensorflow中进行自动微分以实现误差的反向传播、进而计算各参数梯度的技术，这使得我们可以方便地使用梯度更新神经网络的参数。其中，pytorch使用动态计算图设计，tensorflow使用静态计算图设计。

我们的实现中，计算图与自动微分系统被“嵌入”在了层的定义。pytorch在源码中定义了计算图基类，通过重载运算符等方法实现计算图的生成。

基于计算图的MLP定义

 1class MLP:
 2    def __init__(self):
 3        self.model = Sequential([
 4            Linear(2, 4), Sigmoid(),
 5            Linear(4, 4), Sigmoid(),
 6            Linear(4, 2)
 7        ])
 8        self.softmax = Softmax()
 9    
10    def __call__(self, x):
11        return self.model(x)
12
13    def forward(self, x):
14        return self.model(x)
15
16    def backwardAndGradientDescent(self, x, y, learning_rate):
17        '''
18        x: input darta vector, like [[0.5, -1.2], [0.7, 0.3], [-0.2, 0.8]]
19        y: labels vector, like [0, 1, 0]
20        '''
21        batch_size = x.shape[0]
22        logits = self.forward(x)
23
24        grad_output = logits.copy()
25        grad_output[range(batch_size), y] -= 1  # cross entropy gradient
26        grad_output /= batch_size
27
28        for layer in reversed(self.model.layers):
29            grad_output = layer.backward(grad_output, learning_rate)
30    
31    def probability(self, x):
32        '''
33        x: input darta vector, like [[0.5, -1.2], [0.7, 0.3], [-0.2, 0.8]]
34        return: probability vector, like [[0.88, 0.12], [0.45, 0.55],  [0.31, 0.69]]
35        '''
36        batch_size = x.shape[0]
37        logits = self.forward(x)
38        return self.softmax(logits)
39
40    def classify(self, x):
41        return np.argmax(self.probability(x), axis=1)

自动微分机制的数学证明

在一个MLP中，假设batch_size = 1，以分子布局表示向量微分，记 z∈R1×n\boldsymbol{z}\in\mathbb{R}^{1\times n}z∈R1×n、z′,b∈R1×m\boldsymbol{z}',\boldsymbol{b}\in\mathbb{R}^{1\times m}z′,b∈R1×m、W∈Rn×m\boldsymbol{W}\in\mathbb{R}^{n\times m}W∈Rn×m，

z′=σ(zW+b)(1) \boldsymbol{z}'=\sigma\big(\boldsymbol{zW}+\boldsymbol{b}\big)\tag{1} z′=σ(zW+b)(1)

也可以写成标量形式，即

zi′=σ(∑j=1nwjizj+bi),    i=1,2⋯ ,m(2) z'_i=\sigma\Big(\sum^n_{j=1}w_{ji}z_j+b_i\Big),\ \ \ \ i=1,2\cdots,m\tag{2} zi′​=σ(j=1∑n​wji​zj​+bi​),    i=1,2⋯,m(2)

设中间变量 a=Wz+b\boldsymbol{a}=\boldsymbol{Wz}+\boldsymbol{b}a=Wz+b，a∈R1×m\boldsymbol{a}\in\mathbb{R}^{1\times m}a∈R1×m，a\boldsymbol{a}a 表示数据经线性变换后、经非线性映射（激活函数）前的内容，有公式 z′=σ(a)\boldsymbol{z}'=\sigma(\boldsymbol{a})z′=σ(a)，与

ai=∑j=1nwjizj+bi,    i=1,2⋯ ,m(3) a_i=\sum^n_{j=1}w_{ji}z_j+b_i,\ \ \ \ i=1,2\cdots,m\tag{3} ai​=j=1∑n​wji​zj​+bi​,    i=1,2⋯,m(3)

根据链式法则，当梯度传播至 z′\boldsymbol{z}'z′，即已知 ∂L∂z′∣θ\frac{\partial\mathcal{L}}{\partial\boldsymbol{z}'}\big|_{\boldsymbol{\theta}}∂z′∂L​​θ​，其中 L\mathcal{L}L 为损失函数，则

∂L∂ai=∂L∂zi′∂zi′∂ai,    i=1,2⋯ ,m(4) \frac{\partial\mathcal{L}}{\partial a_i}=\frac{\partial\mathcal{L}}{\partial\boldsymbol{z}'_i}\frac{\partial{z'_i}}{\partial{a_i}},\ \ \ \ i=1,2\cdots,m\tag{4} ∂ai​∂L​=∂zi′​∂L​∂ai​∂zi′​​,    i=1,2⋯,m(4)

写作向量形式，即

∂L∂a=∂L∂z′∂z′∂a=∂L∂z′⊙ grad(σ(a))=∂L∂z′⊙σ′(a)(5) \boxed{\frac{\partial\mathcal{L}}{\partial\boldsymbol{a}}=\frac{\partial\mathcal{L}}{\partial\boldsymbol{z}'}\frac{\partial\boldsymbol{z}'}{\partial\boldsymbol{a}}=\frac{\partial\mathcal{L}}{\partial\boldsymbol{z}'}\odot\,\textbf{grad}\big(\sigma(\boldsymbol{a})\big)=\frac{\partial\mathcal{L}}{\partial\boldsymbol{z}'}\odot\sigma'(\boldsymbol{a})}\tag{5} ∂a∂L​=∂z′∂L​∂a∂z′​=∂z′∂L​⊙grad(σ(a))=∂z′∂L​⊙σ′(a)​(5)

所以激活函数σ\sigmaσ在反向传播时，应将 ∂L∂a\frac{\partial\mathcal{L}}{\partial\boldsymbol{a}}∂a∂L​ 传播至低一层。对于不含参数的激活函数，并不需要进行参数的更新，其任务只是传递梯度 ∂L∂a\frac{\partial\mathcal{L}}{\partial\boldsymbol{a}}∂a∂L​。其中⊙\odot⊙表示Hadamard积，在numpy中对应操作符 *。

现在逐个讨论 ∂L∂W\frac{\partial\mathcal{L}}{\partial\boldsymbol{W}}∂W∂L​、∂L∂b\frac{\partial\mathcal{L}}{\partial\boldsymbol{b}}∂b∂L​ 与 ∂L∂z\frac{\partial\mathcal{L}}{\partial\boldsymbol{z}}∂z∂L​。对于∂L∂W\frac{\partial\mathcal{L}}{\partial\boldsymbol{W}}∂W∂L​，i,j∈[1,m]×[1,n]i,j\in[1,m]\times[1,n]i,j∈[1,m]×[1,n]，有

∂L∂wji=∑k=1m∂L∂ak∂ak∂wji=∑k=1m∂L∂ak∂∂wji(∑l=1nwlk zl+bk)=∂L∂ai⋅zj(6) \frac{\partial\mathcal{L}}{\partial w_{ji}}=\sum^m_{k=1}\frac{\partial\mathcal{L}}{\partial a_k}\frac{\partial a_k}{\partial w_{ji}}=\sum^m_{k=1}\frac{\partial\mathcal{L}}{\partial a_k}\frac{\partial}{\partial w_{ji}}\left(\sum^n_{l=1}w_{lk}\,z_l+b_k\right)=\frac{\partial\mathcal{L}}{\partial a_i}\cdot z_j\tag{6} ∂wji​∂L​=k=1∑m​∂ak​∂L​∂wji​∂ak​​=k=1∑m​∂ak​∂L​∂wji​∂​(l=1∑n​wlk​zl​+bk​)=∂ai​∂L​⋅zj​(6)

所以

    ∂L∂W=(z1∂L∂a1z2∂L∂a1⋯zn∂L∂a1z1∂L∂a2z2∂L∂a2⋯zn∂L∂a2⋮⋮⋮z1∂L∂amz2∂L∂am⋯zn∂L∂am)=zT∂L∂a    (7) \boxed{\begin{aligned}\\&\ \ \ \ \frac{\partial\mathcal{L}}{\partial\boldsymbol{W}}=\left(\begin{matrix}z_1\frac{\partial\mathcal{L}}{\partial a_1}&z_2\frac{\partial\mathcal{L}}{\partial a_1}&\cdots&z_n\frac{\partial\mathcal{L}}{\partial a_1}\\z_1\frac{\partial\mathcal{L}}{\partial a_2}&z_2\frac{\partial\mathcal{L}}{\partial a_2}&\cdots&z_n\frac{\partial\mathcal{L}}{\partial a_2}\\\vdots&\vdots&&\vdots\\z_1\frac{\partial\mathcal{L}}{\partial a_m}&z_2\frac{\partial\mathcal{L}}{\partial a_m}&\cdots&z_n\frac{\partial\mathcal{L}}{\partial a_m}\\\end{matrix}\right)=\boldsymbol{z}^T\frac{\partial\mathcal{L}}{\partial\boldsymbol{a}}\ \ \ \ \\&\end{aligned}}\tag{7} ​    ∂W∂L​=​z1​∂a1​∂L​z1​∂a2​∂L​⋮z1​∂am​∂L​​z2​∂a1​∂L​z2​∂a2​∂L​⋮z2​∂am​∂L​​⋯⋯⋯​zn​∂a1​∂L​zn​∂a2​∂L​⋮zn​∂am​∂L​​​=zT∂a∂L​    ​​(7)

接着讨论∂L∂b\frac{\partial\mathcal{L}}{\partial\boldsymbol{b}}∂b∂L​，易见

∂L∂bi=∂L∂ai∂ai∂bi=∂L∂ai×1,    i=1,2⋯ ,m(8) \frac{\partial\mathcal{L}}{\partial b_i}=\frac{\partial\mathcal{L}}{\partial a_i}\frac{\partial a_i}{\partial{b_i}}=\frac{\partial\mathcal{L}}{\partial a_i}\times1,\ \ \ \ i=1,2\cdots,m\tag{8} ∂bi​∂L​=∂ai​∂L​∂bi​∂ai​​=∂ai​∂L​×1,    i=1,2⋯,m(8)

显然

∂L∂b=∂L∂a(9) \boxed{\frac{\partial\mathcal{L}}{\partial\boldsymbol{b}}=\frac{\partial\mathcal{L}}{\partial\boldsymbol{a}}}\tag{9} ∂b∂L​=∂a∂L​​(9)

当batch_size大于111时，∂L∂b\frac{\partial\mathcal{L}}{\partial\boldsymbol{b}}∂b∂L​ 应取np.sum(grad_output, axis=0)而非grad_output。这一步对其他梯度计算而言已经蕴含在矩阵 / 张量乘法中了，但对偏置需要单独实现。

最后讨论 ∂L∂z\frac{\partial\mathcal{L}}{\partial\boldsymbol{z}}∂z∂L​，同理

∂L∂zi=∑j=1m∂L∂aj∂aj∂zi=∑j=1m∂L∂aj∂∂zi(∑k=1nwkjzk+bj)=∑j=1mwij∂L∂aj,    i=1,2⋯ ,n \begin{align*}\frac{\partial\mathcal{L}}{\partial z_i}&=\sum^m_{j=1}\frac{\partial\mathcal{L}}{\partial a_j}\frac{\partial a_j}{\partial z_i}\tag{10}\\&=\sum^m_{j=1}\frac{\partial\mathcal{L}}{\partial a_j}\frac{\partial}{\partial z_i}\left(\sum^n_{k=1}w_{kj}z_k+b_j\right)\tag{11}\\&=\sum^m_{j=1}w_{ij}\frac{\partial\mathcal{L}}{\partial a_j},\ \ \ \ i=1,2\cdots,n\tag{12}\end{align*} ∂zi​∂L​​=j=1∑m​∂aj​∂L​∂zi​∂aj​​=j=1∑m​∂aj​∂L​∂zi​∂​(k=1∑n​wkj​zk​+bj​)=j=1∑m​wij​∂aj​∂L​,    i=1,2⋯,n​(10)(11)(12)​

因此

∂L∂z=∂L∂aWT(13) \boxed{\frac{\partial\mathcal{L}}{\partial\boldsymbol{z}}=\frac{\partial\mathcal{L}}{\partial\boldsymbol{a}}\boldsymbol{W}^T}\tag{13} ∂z∂L​=∂a∂L​WT​(13)

其中∂L∂W\frac{\partial\mathcal{L}}{\partial\boldsymbol{W}}∂W∂L​与∂L∂b\frac{\partial\mathcal{L}}{\partial\boldsymbol{b}}∂b∂L​通过梯度下降及其变种算法参与参数更新，∂L∂z\frac{\partial\mathcal{L}}{\partial\boldsymbol{z}}∂z∂L​则传递给低一层的网络或激活函数。如果要更新网络参数，前向传播时各层应保存输入，以便在反向传播时计算梯度。
