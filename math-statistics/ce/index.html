对交叉熵损失的见解

2026.07.30 · #交叉熵

交叉熵损失的形式

对于回归任务，特别是简单的回归问题，我们通常使用 MSE（Mean Squared Error，均方误差）作为损失函数，少数情况下也使用 MAE（Mean Absolute Error）。MSE 有诸多优良性质，比如光滑、便于求导且导数仍光滑、在某些理想条件下具有凸性且等价于 MLE（Maximum Likelihood Estimation，极大似然估计）。此外，MSE 本身能被分解为偏差的平方、方差与噪声之和，这也为 MSE 提供了一种合理的解释。关于这部分内容，可见于另一篇我在本科时为《回归分析》课程所撰写的笔记：回归分析。

不过，今天我想从统计学与信息论两个角度分别讨论一个在分类任务中被广泛应用的损失函数——CE（Cross Entropy，交叉熵）损失。

CE 的形式十分简单，在 MMM 分类问题中，对于输入样本 xxx ，记模型对 xxx 关于第 mmm 个分类的输出预测概率为 qm(x)q_m(x)qm​(x) 或 q(ym∣x)q(y_m\mid x)q(ym​∣x)，而真实的概率为 pm(x)p_m(x)pm​(x) 或 p(ym∣x)p(y_m\mid x)p(ym​∣x)，则样本 xxx 的 CE 为

CEx=−∑i=1Mpi(x)log⁡2qi(x) CE_x=-\sum^M_{i=1}p_i(x)\log_2q_i(x) CEx​=−i=1∑M​pi​(x)log2​qi​(x)

对于事先给出准确标签的有监督学习，在训练过程中往往有数据的真实标签，因此真实概率 ppp 通常是 One-Hot 编码的，此时 CE 可简化为

CEx=−log⁡2qy(x) CE_x=-\log_2q_{y}(x) CEx​=−log2​qy​(x)

若考虑全部的 NNN 个样本，则取各样本的平均 CE 作为损失函数，即

CE=−1N∑i=1N∑j=1Mpj(xi)log⁡2qj(xi) CE=-\frac{1}{N}\sum^N_{i=1}\sum^M_{j=1}p_j(x_i)\log_2q_j(x_i) CE=−N1​i=1∑N​j=1∑M​pj​(xi​)log2​qj​(xi​)

对于 One-Hot 编码，可进一步简化为

CE=−1N∑i=1Nlog⁡2qyi(xi) CE=-\frac1{N}\sum_{i=1}^{N}\log_2q_{y_i}(x_i) CE=−N1​i=1∑N​log2​qyi​​(xi​)

这应当是人尽皆知的故事，几乎是我们的常识。可是，为什么 CE 能够在（多）分类任务损失函数家族中占据统治地位呢？本文将从统计学与信息论两个视角分别讨论这一点，说明为什么 CE 适合分类任务。

统计学视角

下面将证明最小化 CE 完全等价于最大化似然，因此在将 CE 作为损失函数时，理论上的最优估计正是 MLE。

对于固定输入 xxx 的分类任务，标签 YYY 服从参数为 q(y∣x)q(y\mid x)q(y∣x) 的分类分布（Categorical Distribution）。若忽略输入差异，将所有样本视为来自同一个类别分布，则退化为多项分布。假设样本是独立同分布的，则该分类分布的似然为

L(θ;x,y)=∏i=1Nqθ(yi∣xi) L(\theta;x,y)=\prod^N_{i=1}q_{\theta}(y_i\mid x_i) L(θ;x,y)=i=1∏N​qθ​(yi​∣xi​)

如果所有样本均来自同一个类别分布，则该似然的表达式与多项分布似然的形式 N!k1!k2!⋯kM!∏i=1Mqiki\displaystyle\frac{N!}{k_1!k_2!\cdots k_M!}\prod^M_{i=1}q_i^{k_i}k1​!k2​!⋯kM​!N!​i=1∏M​qiki​​ 只相差常数倍。

接着对上式取对数。取对数有两点原因：

  1. 对似然函数取对数是计算 MLE 的常见手法，目的是将连乘转为连加，方便计算。无论是笔算利用 Lagrange 乘子法求 MLE 的解析解，还是利用计算机通过沿梯度的反向传播与梯度下降优化参数，都能够大幅降低计算量。
  2. 数值上更稳定。如果不取对数，由于 qi∈[0,1]q_i\in[0,1]qi​∈[0,1]，因此当样本量充分大时，不可避免地 ∏i=1Nqθ(yi∣xi)\displaystyle\prod^N_{i=1}q_{\theta}(y_i\mid x_i)i=1∏N​qθ​(yi​∣xi​) 将接近 000。当在计算机上进行计算时，这也是做对数运算的一个重要理由。

取对数后再除样本总数 NNN 以使数值范围可控，有

1Nlog⁡L(θ;x,y)=1N∑i=1Nlog⁡qθ(yi∣xi) \frac1{N}\log L(\theta;x,y)=\frac1{N}\sum_{i=1}^{N}\log q_{\theta}(y_i\mid x_i) N1​logL(θ;x,y)=N1​i=1∑N​logqθ​(yi​∣xi​)

该形式与 CE 仅相差一个负号，因此最大化似然与最小化 CE 是完全等价的。

综上所述，如果将 CE 作为损失函数，则在分类问题中所得到的估计值正是 MLE。

上文所推导出的负对数似然是没有 pj(xi)p_j(x_i)pj​(xi​) 项的，因为在最初分类分布的似然中就隐含了按真实标签的 One-Hot 编码 p(xi)p(x_i)p(xi​) 的结果。

信息论视角

离散随机变量的编码

对于信源编码（Source Coding），我们希望找到一种编码方式，使得平均编码长度足够小。

举一个例子，假设我们作为消息的发送方，将等概率地发送 A、B、C 与 D 四种消息，那么我们可以按下述方式编码：

  • A：00
  • B：01
  • C：10
  • D：11

这样，所有消息的码长均为 2，由于每种消息都具有相同的概率被选中，因此平均编码长度也为 2。易见这是最优编码策略。

可假设我们发送 A 的概率是 12\frac1221​、发送 B 的概率是 14\frac1441​，而发送 C 与 D 的概率均为 18\frac1881​ 呢？如果依然按上述方式编码，则平均编码长度为 12×2+14×2+18×2+18×2=2\frac12\times2+\frac14\times 2+\frac18\times2+\frac18\times2=221​×2+41​×2+81​×2+81​×2=2（bit）。然而，这并不是该情况下的最优编码方案。

最优编码为：

  • A：0
  • B：10
  • C：110
  • D：111

该编码方案的平均码长为 12×1+14×2+18×3+18×3=1.75\frac12\times1+\frac14\times 2+\frac18\times3+\frac18\times3=1.7521​×1+41​×2+81​×3+81​×3=1.75（bit）。这是因为，我们发送 AAA 的概率足够大，因此应当为 AAA 分配最短的编码。

熵与最优编码

构建即时码（Instantaneous Code）的基本要求是任何一个码字都不应是另一个码字的前缀——这是系统无需前瞻便可即时唯一解码的充要条件。在该要求下，我们希望得到最优编码。

事实上，信源编码定理（Source Coding Theorem）指出：对于某个信源，存在一种编码方式使其平均码长任意接近于该信源的熵（Entropy），但不可能低于熵。

这意味着最优编码不会低于熵。下面我们可以简要地证明这一结论。

根据 Gibbs 不等式，对于概率分布 ppp 与 qqq，有

−∑pilog⁡2pi⩽−∑pilog⁡2qi -\sum p_i\log_2 p_i\leqslant-\sum p_i\log_2 q_i −∑pi​log2​pi​⩽−∑pi​log2​qi​

构造辅助概率分布 qi=2−liq_i=2^{-l_i}qi​=2−li​ 并代入，得

−∑pilog⁡2pi⩽−∑pilog⁡2qi=∑pili -\sum p_i\log_2 p_i\leqslant-\sum p_i\log_2 q_i=\sum p_il_i −∑pi​log2​pi​⩽−∑pi​log2​qi​=∑pi​li​

当且仅当 p=qp=qp=q 时 Gibbs 不等式取等，即 pi=qi=2−lip_i=q_i=2^{-l_i}pi​=qi​=2−li​，此时 li=−log⁡2pil_i=-\log_2 p_ili​=−log2​pi​。由于 ∑pili\sum p_il_i∑pi​li​ 为平均码长，因此 −∑pilog⁡2pi-\sum p_i\log_2 p_i−∑pi​log2​pi​ 便是平均码长的下界。这也意味着最优码长理论上满足 li=−log⁡2pil_i=-\log_2 p_ili​=−log2​pi​。

Kraft 不等式表明，唯一可译码的码字长度必须满足充要条件 ∑D−li⩽1\sum D^{-l_i}\leqslant 1∑D−li​⩽1，其中 DDD 为字母表所包含的元素数量，lil_ili​ 为第 iii 个码字长度。对于二进制编码，即 ∑2−li⩽1\sum2^{-l_i}\leqslant1∑2−li​⩽1。因此，我们构造的辅助概率分布 qi=2−liq_i=2^{-l_i}qi​=2−li​ 是合法的，和值不会大于 111。

至于和值不严格等于 1 的问题，只需要令 q0=1−∑2−liq_0=1-\sum 2^{-l_i}q0​=1−∑2−li​ 作为哑元即可。

下界值 −∑pilog⁡2pi-\sum p_i\log_2 p_i−∑pi​log2​pi​ 正是熵（Entropy），记为 H(p)H(p)H(p)。熵有许多符合直觉的性质，比如

  1. 非负且有界，0⩽H(p)⩽log⁡2n0\leqslant H(p)\leqslant\log_2n0⩽H(p)⩽log2​n，其中 nnn 是离散随机变量可能的取值数量；
  2. 对称性，H(p1,p2,⋯ ,pn)=H(pπ(1),pπ(2),⋯ ,pπ(n))H(p_1,p_2,\cdots,p_n)=H(p_{\pi(1)},p_{\pi(2)},\cdots,p_{\pi(n)})H(p1​,p2​,⋯,pn​)=H(pπ(1)​,pπ(2)​,⋯,pπ(n)​)；
  3. 可加性，H(p1,p2)=H(p1)+H(p2∣p1)H(p_1,p_2)=H(p_1)+H(p_2\mid p_1)H(p1​,p2​)=H(p1​)+H(p2​∣p1​)；
  4. 凹性，当 λ∈[0,1]\lambda\in[0,1]λ∈[0,1]，有 H(λp+(1−λ)q)⩾λH(p)+(1−λ)H(q)H\big(\lambda p+(1-\lambda)q\big)\geqslant\lambda H(p)+(1-\lambda)H(q)H(λp+(1−λ)q)⩾λH(p)+(1−λ)H(q)。

霍夫曼编码（Huffman Coding）就是一种最优的信源编码，但这不是本文的重点。总而言之，熵刻画了一个概率分布本身所蕴含的信息量，也等价于对该信源进行无损编码时所能达到的理论最小平均码长。

如何理解熵刻画了概率分布的信息量？简而言之：概率越大，码长应越短。

由于小概率事件出现时更加出人意料，因此我们需要更多比特描述它，这也意味着它携带了更多信息。熵正是这种信息量在整个概率分布上的平均值。

对于连续随机变量，微分熵（Differential Entropy）的定义为 −∫p(x)log⁡p(x)dx\displaystyle-\int p(x)\log p(x)\mathrm{d}x−∫p(x)logp(x)dx，这是一种常见的针对连续随机变量的熵定义。微分熵有许多特殊的特性，对于分类问题，通常将分类结果视为某个离散随机变量的值，因此不会涉及微分熵，故不做深入介绍。

交叉熵

在实际问题中，我们往往并不知道真实分布 ppp，而只能通过建立模型 qqq 近似 ppp。即，按照模型输出的分布设计最优码本，却用于编码来自真实分布的数据。CE 恰好给出了此时所得到的平均码长。

对于平均码长 ∑pili\sum p_il_i∑pi​li​，当我们使用 qqq 编码时，最优码长理论上有 li=−log⁡2qil_i=-\log_2 q_ili​=−log2​qi​，代入平均码长公式，得到

−∑pilog⁡2qi -\sum p_i\log_2 q_i −∑pi​log2​qi​

该值正是 CE，通常记为 H(p,q)H(p,q)H(p,q)。

因此，Gibbs 不等式也可以被写为下述形式

H(p)⩽H(p,q) H(p)\leqslant H(p,q) H(p)⩽H(p,q)

而不等式的差值 H(p,q)−H(p)=∑pilog⁡2piqiH(p,q)-H(p)=\sum p_i\log_2\frac{p_i}{q_i}H(p,q)−H(p)=∑pi​log2​qi​pi​​ 正是 KL 散度（Kullback-Leibler Divergence）DKL(p∥q)D_{\text{KL}}(p\Vert q)DKL​(p∥q)。KL 散度衡量了两个分布的近似程度。

所以，当我们最小化交叉熵，便最小化了 KL 散度，使得模型的预测分布最接近真实分布，此时用 qqq 编码 ppp 的平均码长逼近其理论下界——熵。

不难推导出 CE 不具备对称性。熵刻画了分布自身的不确定性，而交叉熵刻画了使用一个分布编码另一个分布的不确定性，二者的语义便决定了 CE 不具备熵那样的对称性。

熵可被视为 CE 的特例，CE 可被视为熵的推广——H(p,p)=H(p)H(p,p)=H(p)H(p,p)=H(p)。

如何理解「按照模型输出的分布设计最优码本，却用于编码来自真实分布的数据」呢？我们假设，模型认为 (A,B,C,D)(A,B,C,D)(A,B,C,D) 的概率均为 14\frac1441​，于是系统按该分布设计码本 (A:00,B:01,C:10,D:11)(A:00,B:01,C:10,D:11)(A:00,B:01,C:10,D:11)。然而，实际数据的分布可能是上文例子中的 (12,14,18,18)\big(\frac12,\frac14,\frac18,\frac18\big)(21​,41​,81​,81​)，因此当该码本被用于编码这一真实数据时，平均编码长度为 222 bit，并未达到上文所分析出的最小平均编码长度 1.751.751.75 bit。

此时，真实分布的熵为 H(p)=1.75H(p)=1.75H(p)=1.75（bit），模型分布与真实分布之间的交叉熵为 H(p,q)=2H(p,q)=2H(p,q)=2（bit），而 KL 散度为 DKL(p∥q)=H(p,q)−H(p)=0.25D_{\text{KL}}(p\Vert q)=H(p,q)-H(p)=0.25DKL​(p∥q)=H(p,q)−H(p)=0.25（bit）。这意味着，由于模型对真实分布的误判，导致编码平均多付出了 0.250.250.25 bit 成本。

补充讨论

上文分别从统计学和信息论的视角论证了在分类任务中使用 CE 作为损失的合理性。除此之外，CE 在深度学习中的广泛应用还有一个重要原因：当它与 softmax 配合使用时，梯度具有十分简洁的形式。

记 logits 为 zzz、softmax 输出为 qi=ezi∑jezjq_i=\frac{e^{z_i}}{\sum_j e^{z_j}}qi​=∑j​ezj​ezi​​，则 CE 关于 ziz_izi​ 的梯度为

∂CE∂zi=qi−pi \frac{\partial CE}{\partial z_i}=q_i-p_i ∂zi​∂CE​=qi​−pi​

可以看到，该梯度与线性回归中 MSE 关于预测值的梯度 y^−y\hat{y}-yy^​−y 在形式上完全一致，均为「预测值减去真实值」。

相比之下，若使用 MSE 配合 sigmoid 或 softmax 输出，根据链式法则，在梯度中还需要乘上 sigmoid（或 softmax）的导数。当模型给出一个置信度极高但实际错误的预测时，由于此时输出已进入饱和区域，故导数趋近于零，从而使整体梯度显著减小，导致参数更新缓慢。

但 CE 与 softmax 在联合使用时，该导数项恰好在求导时被抵消，因此即使模型做出了高置信度的错误预测，仍能够产生较大的梯度，这有利于模型优化。

因此，CE 不仅在统计学与信息论的视角下是合理的、有意义的，在数值上也是利于训练的，兼具理论与工程价值。

对于二分类任务，CE 退化为

CE=−1N∑i=1N[yilog⁡qi+(1−yi)log⁡(1−qi)] CE = -\frac{1}{N}\sum_{i=1}^N \bigl[ y_i \log q_i + (1-y_i) \log(1-q_i) \bigr] CE=−N1​i=1∑N​[yi​logqi​+(1−yi​)log(1−qi​)]

这恰好是 Logistic 回归所使用的负对数似然损失。
